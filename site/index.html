topic-hub-catalog

A public, curated subset of a personal Obsidian library catalog: a keyless web-search MCP server, its source adapters, a deterministic catalog worker, and dated legal research.

Access mode

robots.txt governs crawlers; API Terms of Use govern API clients. This project is an API client: low-frequency targeted GET requests to documented endpoints, with a descriptive User-Agent. It does not crawl pages.
